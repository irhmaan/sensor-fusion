# Simulate a variety of sensor data for a mobile bot

Sort of data we can include like:

    1. Odometry (position & heading from wheel integration)
    2. Wheel encoders (ticks + velocities)
    3. Distance sensors (ultrasonic + IR)
    4. IMU (accelerometer, gyroscope, magnetometer)
    5. Motor feedback (PWM + current draw)
    6. Battery status
    7. Environment (temperature, humidity, light)
    8. Simplified LIDAR (5-point scan)
